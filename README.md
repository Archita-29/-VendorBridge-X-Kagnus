# VendorBridge X Kagnus

VendorBridge is a procurement and vendor management ERP project.

## Week 1 scope

- Authentication and role-based authorization
- Procurement dashboard
- Vendor management and CRUD operations
- Search, filtering, and vendor status indicators

## Technology stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: FastAPI, Python
- Database: PostgreSQL
- Database access: SQLAlchemy and Alembic
- Local database environment: Docker Compose

## Project structure

- `frontend/` — frontend application
- `backend/` — backend application
- `infra/` — local infrastructure configuration
- `docs/` — design references and project documentation

## Setup

Setup instructions will be completed as the application is implemented.

## Security

Never commit real credentials, `.env` files, or production secrets.
